## TypeTool Highlights

- **Glyph Edit:** TypeTool glyph edit is the window where you move outline points of one character for a first type study.
- **Font Family:** TypeTool font family groups a regular face with a bold or italic companion when the exercise calls for more than one style.
- **Side Bearing:** TypeTool side bearing is the space on the left and right of a glyph before any special pair adjustment.
- **Kerning Pair:** TypeTool kerning pair changes the gap between two particular letters after the side bearings are roughly right.
- **Outline Point:** TypeTool outline point is a single anchor on the curve, the place you nudge when a bowl or a stem looks uneven.

## What Is TypeTool

TypeTool is a focused editor for learning how a letter is built. TypeTool glyph edit shows the outline. TypeTool outline point is what you actually move. A design student, or a careful hobbyist making a practice face, can understand stems, curves, and spacing without taking on a large font-production suite.

TypeTool side bearing teaches the first kind of space: each letter’s own margins. TypeTool kerning pair teaches the second kind: exceptions between neighbors. TypeTool font family is there when the assignment asks for regular and bold as relatives, not as unrelated files. Keep the character set small. A study of lowercase, or of figures, is more honest than a half-finished encyclopedia of glyphs.

The order matters. Draw or correct the shape in TypeTool glyph edit by moving TypeTool outline point markers. Set TypeTool side bearing until words are even. Only then add a TypeTool kerning pair. If the course wants two styles, relate them in TypeTool font family so names and proportions stay cousins.

## Starting with TypeTool

Prerequisites: A compatible computer, a small lettering brief, and permission to run TypeTool.

1. **Prepare:** Choose lowercase or capitals, not both, for the first week.
2. **Open A Glyph:** Start TypeTool glyph edit on a simple letter such as n or H.
3. **Move Points:** Adjust TypeTool outline point markers until the stem and curve match your sketch.
4. **Set Margins:** Give that letter a TypeTool side bearing and test it beside o or n.
5. **Fix A Pair:** Add one TypeTool kerning pair only after a word looks uneven.
6. **Relate Styles:** If you need bold, create it inside the same TypeTool font family.
